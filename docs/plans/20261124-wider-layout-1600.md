# Wider layout — 1600px header and page content

## Context

The new "Contact" nav item filled the header. At a 1440px screen, only 24px of free
space was left between the tagline and the nav, and "About Your Attorney" wrapped to two
lines. The header and the page content were both capped at 1280px.

## Changes

### Header and content width: 1280px → 1600px

`wp-content/themes/hello-biz-child/assets/child.css`:

| Rule | Before | After |
|------|--------|-------|
| `.hp-header__inner` | `calc(1280px + 2 * var(--hp-gutter))` | `calc(1600px + 2 * var(--hp-gutter))` |
| `.hp-footer__inner` | `calc(1280px + 2 * var(--hp-gutter))` | `calc(1600px + 2 * var(--hp-gutter))` |
| `.hp-article__inner`, `.hp-prose__inner`, `.hp-postnav__inner` (blog posts) | `calc(1280px + 48px)` | `calc(1600px + 48px)` |

The blog post reading column stays at 70ch (`.hp-prose__inner > *`).

Elementor: every container with `boxed_width` 1280px changed to 1600px (53 containers on
20 pages). The script walked `_elementor_data` on each page and cleared the page's
`_elementor_css`. Then `studio wp elementor flush-css` ran.

The Home page has no 1280px containers. Its sections keep their own narrower widths.

### Header bar at every width

The phone number stays beside the booking button. A trial put it below the button, but
the stacked bar did not look right, so that change was reverted.

The screen width, not the 1600px cap, limits the header on screens narrower than
1664px. These rules keep the bar clean there:

| Width | Rule |
|-------|------|
| 1025px and wider | The logo never shrinks (`flex-shrink: 0`). A full bar squeezed it to 118px wide at 1281px, out of shape. A top-level nav link never breaks onto two lines (`white-space: nowrap`). |
| 1281–1400px | The tagline shows, so the nav uses the compact spacing (16px gap, 9px link padding, 14px text) and the phone shows as an icon only. |
| ≤1280px | Compact spacing and phone icon only (this breakpoint was 1180px). The tagline is hidden. |
| 1025–1100px | Tighter spacing (16px bar gap, 12px nav gap, 6px link padding), so the bar does not overflow. |
| All widths | `object-fit: contain` on the logo. On phones the bar may still narrow the logo, and it then scales down evenly instead of out of shape. |

The tagline is now 12px (was 14px).

### Phone menu: one booking button

At 1024px and narrower, the open menu has its own full-width "Book a free consultation"
button. The bar's "Book a consultation" button is now hidden while the menu is open, so
the menu shows only one booking button.

### Home page button hover colors

The text hover color of 4 Home page buttons was stored in `button_hover_color`, which
Elementor ignores. The correct control is `hover_color`. On hover, "Call (415)
692-1503" showed navy text on navy, and the "415-692-1503" CTA button showed light text
on a light background. The value now sits in `hover_color` on all 4 buttons (database
change, page 83).

### Theme version

`style.css` Version 1.8.11 → 1.9.0, so browsers load the new `child.css`.

## Deploy

The CSS goes with git. The Elementor container widths are in the database and go live
with `studio push`. Both must go live together, or the header and the content will not
line up.

## Verification

- 1920px: the logo, the H1, the body content, and the footer start at the same x
  (153px) on Contact, FAQs, Book, Pricing, Services, Estate Law, Real Estate, the
  service, booking, and pricing sub-pages, the Blog page, and a blog post.
- 1025px to 1920px: every nav link is one line of text (counted by text line, not by
  link height, because two short lines fit inside a 44px link). The logo is 191 × 36px.
  The bar does not overflow.
- 320px, 375px, 1024px: the menu button stays on screen. The logo keeps its shape.
- Open phone menu: one booking button. The menu still lists Contact.
- Home page: both phone buttons show readable text on hover.
- No horizontal scroll at any width.
